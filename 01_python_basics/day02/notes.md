## 二、核心知识点

### 2.1 if / else 条件判断

`if` 用于根据条件决定是否执行某段代码，`else` 用于处理条件不成立的情况。

基本语法：

```python
if condition:
    # 条件成立时执行
    print("条件成立")
else:
    # 条件不成立时执行
    print("条件不成立")
```

例如：

```python
age = 20

if age >= 18:
    print("成年人")
else:
    print("未成年人")
```

运行结果：

```text
成年人
```

**知识要点：**

1. 条件表达式可以得到 `True` 或 `False`。
2. `if` 和 `else` 后面需要添加冒号 `:`。
3. 条件代码块通常采用四个空格缩进。
4. 同一个 `if/else` 结构只会选择一个分支执行。
5. 可以只有 `if`，不一定需要 `else`。

### 2.2 比较运算符

| 运算符 | 含义 | 示例 |
|---|---|---|
| `>` | 大于 | `a > b` |
| `<` | 小于 | `a < b` |
| `>=` | 大于或等于 | `a >= b` |
| `<=` | 小于或等于 | `a <= b` |
| `==` | 等于 | `a == b` |
| `!=` | 不等于 | `a != b` |

例如：

```python
age = 18

print(age >= 18)
print(age < 18)
print(age == 18)
```

输出：

```text
True
False
True
```

需要区分：

- `=`：赋值运算符。
- `==`：比较两个值是否相等。

### 2.3 elif 多分支条件判断

当程序需要区分多个情况时，可以使用 `elif`。

```python
temperature = 28

if temperature >= 30:
    print("天气炎热")
elif temperature >= 20:
    print("天气温暖")
else:
    print("天气较冷")
```

运行结果：

```text
天气温暖
```

**重要规则：**

- 程序从上往下检查条件。
- 一旦某个条件成立，就执行对应分支。
- 同一条件结构中，后续 `elif` 和 `else` 不再执行。
- `elif` 可以出现多次。
- `else` 最多出现一次，且必须放在最后。

条件判断的顺序非常重要。

例如：

```python
score = 95

if score >= 60:
    print("及格")
elif score >= 90:
    print("优秀")
```

输出为：

```text
及格
```

因为第一个条件已经成立。

在成绩等级这类问题中，通常需要先判断高分区间，再判断低分区间。

### 2.4 逻辑运算符 and / or / not

Python 中常见的三个逻辑运算符：

| 运算符 | 含义 | 判断规则 |
|---|---|---|
| `and` | 并且 | 两个条件同时成立 |
| `or` | 或者 | 至少有一个条件成立 |
| `not` | 取反 | 反转条件的真假 |

#### and

```python
age = 24
is_active = True

if age >= 18 and is_active:
    print("允许访问")
```

两个条件都成立时，才会执行输出。

#### or

```python
score = 105

if score < 0 or score > 100:
    print("成绩无效")
```

只要其中一个条件成立，就会进入该分支。

#### not

```python
is_active = False

if not is_active:
    print("账号未激活")
```

`not False` 的结果为 `True`。

#### 逻辑运算符优先级

在常见布尔表达式中：

```text
not > and > or
```

建议在复杂条件中使用括号明确逻辑关系。

**补充知识：**

`and` 和 `or` 具有短路求值特性，当左侧结果已经足以决定整个表达式的结果时，右侧表达式就不会继续计算。

### 2.5 for 循环

`for` 循环常用于遍历可迭代对象。

基本语法：

```python
for i in range(5):
    print(i)
```

运行结果：

```text
0
1
2
3
4
```

#### range() 的三种形式

**1. range(stop)**

```python
for i in range(5):
    print(i)
```

生成从 0 到 4 的整数。

**2. range(start, stop)**

```python
for i in range(1, 6):
    print(i)
```

生成从 1 到 5 的整数。

**3. range(start, stop, step)**

```python
for i in range(2, 11, 2):
    print(i)
```

依次输出：

```text
2
4
6
8
10
```

**重要结论：`range()` 不包含结束值 `stop`。**

因此，如果需要遍历 1 到 n：

```python
for i in range(1, n + 1):
    print(i)
```

### 2.6 累加变量

累加变量用于保存多次计算后的累计结果。

```python
total = 0

for i in range(1, 6):
    total += i

print(total)
```

运行结果：

```text
15
```

其中：

```python
total += i
```

等价于：

```python
total = total + i
```

对于从 1 开始的整数求和，通常将 `total` 初始化为 0。

### 2.7 while 循环

`while` 表示只要条件成立，就持续执行循环体。

```python
count = 1

while count <= 5:
    print(count)
    count += 1
```

输出：

```text
1
2
3
4
5
```

**执行过程：**

1. 初始化循环变量。
2. 判断循环条件。
3. 条件成立则执行循环体。
4. 更新循环变量。
5. 重新判断条件。
6. 条件不成立时退出循环。

需要特别注意，循环体中应有机会使条件变为 `False`，否则可能出现无限循环。

### 2.8 for 与 while 的区别

| 对比 | for | while |
|---|---|---|
| 主要用途 | 遍历数据、整数范围 | 根据条件重复执行 |
| 控制方式 | 依次获取元素 | 每轮重新检查条件 |
| 典型场景 | 求和、遍历列表 | 输入校验、持续等待 |
| 常见问题 | 范围边界错误 | 无限循环 |

**选择原则：**

- 需要遍历指定范围或数据时，优先考虑 `for`。
- 需要重复执行直到某个条件改变时，优先考虑 `while`。

### 3.5 练习五：while 输入校验与整数累加

**文件路径：** `code/while_sum.py`

#### ① 练习目标

综合运用 `while` 和 `for`，实现正整数输入校验及累加计算。

#### ② 题目要求

- 接收一个正整数 n。
- 如果 n 小于或等于 0，要求用户重新输入。
- 使用 `while` 实现重复输入。
- 使用 `for` 计算 1 到 n 的整数之和。

```python

# 使用 while 验证正整数

    print("输入无效，请重新输入")
    n = int(input("请输入正整数："))

# 使用 for 循环求和
total = 0

for i in range(1, n + 1):
    total += i

print(f"1 到 {n} 的整数之和为：{total}")
```

#### ④ 运行结果

```text
请输入正整数：-3
输入无效，请重新输入

输入无效，请重新输入

1 到 5 的整数之和为：15
```

测试情况：

| 输入顺序 | 结果 |
|---|---|
| 5 | 15 |
| -1 → 3 | 6 |
| 0 → 0 → 10 | 55 |
| 1 | 1 |

#### ⑤ 知识总结

- `while` 根据条件控制重复执行。
- 在循环内部更新变量，才能使循环条件发生变化。
- `while` 适合重复输入校验。
- `for` 适合遍历已确定的整数范围。
- `while` 退出后，可以继续执行后面的求和逻辑。

本次练习的关键结构：

```python
while n <= 0:
    n = int(input("请输入正整数："))
```

只有当 n 大于 0 时，才会退出循环。

#### ⑥ 改进方向

- 使用 `try/except` 处理非数字输入。
- 将求和逻辑封装为函数。
- 当输入数字非常大时，可以考虑其他计算方式。
- 学习 `break` 和 `continue` 后，比较不同循环控制方法。

## 四、今日编程规范总结

### 4.1 注意缩进

Python 使用缩进表示代码块。

`if`、`elif`、`else`、`for`、`while` 后面的代码一般缩进四个空格。

### 4.2 注意冒号

以下语句后面需要添加冒号：

- `if`
- `elif`
- `else`
- `for`
- `while`

例如：

```python
if age >= 18:
    print("成年人")
```

### 4.3 条件顺序要合理

使用 `elif` 时，应该考虑前面的条件会排除哪些情况，避免逻辑重叠或遗漏。

### 4.4 注意循环变量更新

对于 `while` 循环，应当确保循环条件有机会变为 `False`，避免无限循环。

### 4.5 正确放置输出语句

程序是否执行某一行代码，取决于代码所在的缩进层级。

要特别注意某条输出语句是在条件内部，还是条件外部。

### 4.6 主动进行边界测试

不要只测试正常输入，还应考虑：

- 等于边界值
- 小于最小值
- 大于最大值
- 输入 0
- 多次输入非法值

## 五、今日问题与反思

### 5.1 elif 条件判断顺序

**问题：** 多个条件同时可能成立时，程序执行哪个分支？

**原因：** `if/elif/else` 从上到下判断，并在第一个成立的分支执行后跳过其余分支。

**解决方法：** 根据业务规则合理安排条件顺序。

### 5.2 and 条件的使用

**问题：** 访问权限判断中是否一定需要 `and`？

**分析：** 在合理安排的 `elif` 结构中，前面的分支可能已经排除了未激活账号，因此有时不需要重复判断。

**学习收获：** 逻辑运算不仅要理解语法，还要理解前置条件与分支之间的关系。

### 5.3 and 条件缺少冒号

**问题：** 补充的 `elif age >= 18 and is_active` 缺少结尾的冒号。

**原因：** Python 条件语句必须以 `:` 引出代码块。

**解决方法：** 编写分支语句后检查冒号与缩进是否正确。

### 5.4 for 循环求和的输出位置

**问题：** 当输入非正整数时，原程序仍然输出求和结果。

**原因：** 输出语句位于 `if/else` 代码块之外。

**改进方向：** 将输出放在有效输入分支中，或使用 `while` 重复输入。

### 5.5 while 循环退出条件

**问题：** 如何避免 `while` 无限循环？

**解决方法：** 确保循环过程中有机会更新与条件相关的变量，使退出条件最终能够成立。
