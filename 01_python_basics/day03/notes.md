## 二、核心知识点

### 2.1 字符串 str 进阶

字符串是由字符组成的有序、不可变序列。

例如：

```python
text = "Python"

print(text[0])
print(text[-1])
print(text[0:3])
print(len(text))
```

运行结果：

```text
P
n
Pyt
6
```

**知识要点：**

1. 字符串索引从 0 开始。
2. 负数索引可以从末尾访问字符。
3. 切片包含起始位置，不包含结束位置。
4. `len()` 用于获取字符串长度。
5. 字符串属于不可变类型，不能通过索引直接修改字符。

**常用字符串方法：**

| 方法 | 作用 | 示例 |
|---|---|---|
| `strip()` | 删除首尾空白 | `" hi ".strip()` |
| `upper()` | 转换为大写 | `"python".upper()` |
| `lower()` | 转换为小写 | `"PYTHON".lower()` |
| `replace()` | 替换指定内容 | `"abc".replace("a", "A")` |
| `split()` | 按分隔符拆分 | `"a,b".split(",")` |

例如：

```python
text = "  Python Agent  "

text = text.strip()

print(text.upper())
print(text.lower())
```

运行结果：

```text
PYTHON AGENT
python agent
```

### 2.2 字符串索引、切片与遍历

**正数索引：**

```python
text = "Python"

print(text[0])
print(text[2])
```

输出：

```text
P
t
```

**负数索引：**

```python
print(text[-1])
print(text[-2])
```

输出：

```text
n
o
```

**字符串切片：**

```python
print(text[:3])
print(text[3:])
print(text[::2])
```

输出：

```text
Pyt
hon
Pto
```

**使用 for 遍历字符串：**

```python
for char in text:
    print(char)
```

运行结果：

```text
P
y
t
h
o
n
```

**重要区别：**

- `text[0]`：访问不存在的索引会触发 `IndexError`。
- `text[:3]`：即使字符串不足三个字符也可以正常截取。
- 对空字符串使用 `text[0]` 会报错，应当先检查是否为空。

### 2.3 列表 list

列表用于存储多个有序元素，属于可变数据类型。

```python
scores = [85, 92, 76, 88, 95]

print(scores[0])
print(scores[-1])
```

运行结果：

```text
85
95
```

**列表常用操作：**

| 操作 | 作用 |
|---|---|
| `scores[0]` | 获取第一个元素 |
| `scores[-1]` | 获取最后一个元素 |
| `scores[2] = 80` | 修改第三个元素 |
| `scores.append(90)` | 末尾添加元素 |
| `scores.remove(88)` | 删除第一个值为 88 的元素 |
| `scores.pop()` | 删除并返回最后一个元素 |
| `len(scores)` | 获取元素数量 |
| `max(scores)` | 获取最大值 |
| `min(scores)` | 获取最小值 |

例如：

```python
scores = [85, 92, 76]

scores[2] = 80
scores.append(90)

print(scores)
```

运行结果：

```text
[85, 92, 80, 90]
```

**使用 for 遍历列表：**

```python
total = 0

for score in scores:
    total += score

print(total)
```

输出：

```text
347
```

列表可以直接修改元素，而字符串不能直接通过索引修改。

### 2.4 元组 tuple

元组是有序、不可修改的序列。

```python
student = ("小明", 24, "计算机科学与技术")

print(student[0])
print(student[-1])
```

输出：

```text
小明
计算机科学与技术
```

**元组解包：**

```python
name, age, subject = student

print(name)
print(age)
print(subject)
```

输出：

```text
小明
24
计算机科学与技术
```

**重要规则：**

- 元组通常使用 `()` 表示。
- 支持索引和切片。
- 元组本身的元素引用不能重新赋值。
- 解包时，普通情况下变量数量需要与元素数量对应。
- 单元素元组需要在元素后添加逗号。

例如：

```python
number = (10,)
```

元组本身不可变，但如果其中包含列表等可变对象，这些内部对象仍可能发生变化。

### 2.5 集合 set

集合用于保存不重复的元素，可以进行集合运算。

```python
skills_a = {"Python", "Java", "Git"}
skills_b = {"Python", "C++", "Git"}
```

**集合运算：**

| 运算符 | 含义 | 结果元素 |
|---|---|---|
| `&` | 交集 | Python、Git |
| `\|` | 并集 | Python、Java、Git、C++ |
| `-` | 差集 A-B | Java |

例如：

```python
print(skills_a & skills_b)
print(skills_a | skills_b)
print(skills_a - skills_b)
```

集合元素的显示顺序可能不同。

**添加和删除元素：**

```python
skills_a.add("Docker")
skills_a.discard("Java")

print(skills_a)
```

修改后的集合包含：

```text
Python、Git、Docker
```

**成员判断：**

```python
print("Python" in skills_a)
```

运行结果：

```text
True
```

**知识要点：**

1. 集合不保存重复元素。
2. 集合不支持通过数字索引访问。
3. `add()` 用于添加元素。
4. `remove()` 删除不存在的元素时会报错。
5. `discard()` 删除不存在的元素时不会报错。
6. `in` 可用于判断元素是否存在。

### 2.6 字典 dict

字典用于保存键值对（key-value）。

```python
student = {
    "name": "小明",
    "age": 24,
    "score": 85
}
```

**通过键访问：**

```python
print(student["name"])
print(student["age"])
```

输出：

```text
小明
24
```

**使用 get()：**

```python
print(student.get("height", "未知"))
```

输出：

```text
未知
```

**修改和新增：**

```python
student["score"] = 95
student["city"] = "北京"
```

**删除：**

```python
student.pop("age")
```

**遍历字典：**

```python
for key, value in student.items():
    print(f"{key}：{value}")
```

**常用字典操作：**

| 方法或语法 | 作用 |
|---|---|
| `dict[key]` | 获取指定键对应的值 |
| `dict.get(key, default)` | 获取值，支持默认值 |
| `dict[key] = value` | 修改或添加键值对 |
| `dict.pop(key)` | 删除指定键 |
| `dict.keys()` | 获取所有键的视图 |
| `dict.values()` | 获取所有值的视图 |
| `dict.items()` | 获取键值对的视图 |
| `key in dict` | 判断键是否存在 |

### 2.7 break、continue 与空容器判断

**break：退出循环。**

```python
while True:
    command = input("请输入命令：")

    if command == "exit":
        break
```

**continue：跳过本轮剩余语句。**

```python
for i in range(1, 6):
    if i == 3:
        continue

    print(i)
```

运行结果：

```text
1
2
4
5
```

**判断空字典：**

```python
students = {}

print(len(students))
print(bool(students))
print(students is None)
```

输出：

```text
0
False
False
```

需要注意：空字典 `{}` 并不是 `None`。

常见的非空字典判断：

```python
if len(students) != 0:
    print("存在学生记录")
else:
    print("暂无学生记录")
```

也可以写成：

```python
if students:
    print("存在学生记录")
else:
    print("暂无学生记录")
```

### 2.8 Python 常用数据结构的区别

| 对比 | str | list | tuple | set | dict |
|---|---|---|---|---|---|
| 有序 | 是 | 是 | 是 | 否 | 保留插入顺序 |
| 可修改 | 否 | 是 | 否 | 是 | 是 |
| 允许重复 | 是 | 是 | 是 | 否 | 键不可重复 |
| 支持数字索引 | 是 | 是 | 是 | 否 | 否 |
| 典型用途 | 文本处理 | 数据列表 | 固定信息 | 去重与集合运算 | 结构化信息 |

**选择原则：**

- 处理文本时使用 `str`。
- 保存需要增删改查的有序数据时使用 `list`。
- 保存固定的一组数据时可以使用 `tuple`。
- 去重或进行集合比较时使用 `set`。
- 需要通过名称查找信息时使用 `dict`。

以下代码保留实际提交逻辑，统一调整 f-string 内部引号。

```python
# 创建学生信息字典
```

```python
# 初始化学生字典
student = {}

# 主菜单循环
while True:
    # 输出提示信息
    print("==== 学生成绩管理系统 ====")
    print("1. 添加学生")
    print("2. 查询成绩")
    print("3. 修改成绩")
    print("4. 删除学生")
    print("5. 显示所有学生")
    print("0. 退出系统")

    command = int(input("请选择操作："))

    if command == 1:
        print("==== 添加学生 ====")
        name = input("请输入学生姓名：")
        score = int(input("请输入学生成绩："))

        if name in student:
            print("学生已存在！")
        elif score < 0 or score > 100:
            print("成绩无效！")
        else:
            student[name] = score
            print("添加成功！")

    elif command == 2:
        print("==== 查询成绩 ====")
        name = input("请输入学生姓名：")

        if name in student:
            print(f"{name}的成绩是：{student[name]}")
        else:
            print("学生不存在！")

    elif command == 3:
        print("==== 修改成绩 ====")
        name = input("请输入学生姓名：")
        score = int(input("请输入学生成绩："))

        if name in student:
            if score < 0 or score > 100:
                print("成绩无效！")
            else:
                student[name] = score
                print("修改成功！")
        else:
            print("学生不存在！")

    elif command == 4:
        print("==== 删除学生 ====")
        name = input("请输入学生姓名：")

        if name in student:
            student.pop(name)
            print("删除成功！")
        else:
            print("学生不存在！")

    elif command == 5:
        print("==== 显示所有学生 ====")

        if len(student) != 0:
            for name, score in student.items():
                print(f"{name}：{score}")
        else:
            print("暂无学生记录")

    elif command == 0:
        print("==== 退出系统 ====")
        print("退出成功！")
        break

    else:
        print("无效操作！")
```

## 四、今日编程规范总结

### 4.1 注意不同数据结构的特性

字符串和元组本身不可修改，而列表、集合和字典可以修改。

选择数据结构时，应结合元素是否需要修改、是否允许重复，以及是否需要通过键访问等要求。

### 4.2 注意索引和切片边界

字符串、列表和元组都支持索引与切片。

访问不存在的单个索引可能触发 `IndexError`，而切片通常可以安全处理范围超出长度的情况。

### 4.3 注意方法的使用场景

- 列表添加元素：`append()`。
- 集合添加元素：`add()`。
- 集合删除元素：`discard()` 或 `remove()`。
- 字典删除键：`pop()`。

不同数据结构的方法不能随意混用。

### 4.4 注意嵌套代码的缩进

当 `while`、`if`、`for` 嵌套使用时，要清晰区分每个代码块。

使用四个空格作为一级缩进。

### 4.5 正确判断空容器

不要将空字典与 `None` 混淆。

可以使用：

```python
if len(student) != 0:
    print("存在数据")
```

或者：

```python
if student:
    print("存在数据")
```

### 4.6 统一 f-string 的引号

对于兼容 Python 3.11 及更早版本的代码，可采用外层双引号、内部单引号：

```python
print(f"姓名：{student['name']}")
```

## 五、今日问题与反思

### 5.1 字符串为空时的索引问题

**问题：** 对空字符串使用 `text[0]` 会发生什么？

**原因：** 空字符串没有任何字符，因此不存在索引 0。

**解决方法：** 访问首字符前先判断字符串是否为空。

### 5.2 列表修改后遗漏完整输出

**问题：** 原始列表练习虽然计算正确，但没有输出修改后的完整列表。

**原因：** 只检查了统计结果，没有逐项核对题目要求。

**解决方法：** 补充 `print(scores)`，并建立按要求验收的习惯。

### 5.3 f-string 内外层引号

**问题：** 在元组与集合练习、字典练习中，部分 f-string 使用了相同的内外层双引号。

**原因：** 不同 Python 版本对 f-string 表达式的解析规则存在差异。

**解决方法：** 使用不同的内外层引号，提高兼容性。

### 5.4 空字典与 None 的区别

**问题：** 学生成绩管理系统中使用 `student is not None` 判断学生记录是否为空。

**原因：** `{}` 是一个空字典对象，不是 `None`。

**解决方法：** 修改为 `len(student) != 0`，正确处理空字典与非空字典。

### 5.5 多功能程序的结构设计

**问题：** 如何将添加、查询、修改、删除、显示等功能整合进一个程序？

**分析：** 需要同时考虑主循环、菜单判断、数据存储和各种边界情况。

**学习收获：** 可以使用 `while True` 管理主循环，并通过 `if/elif/else` 分配不同功能。
