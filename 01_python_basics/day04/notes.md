## 二、核心知识点

### 2.1 函数的定义与调用

函数是将具有特定功能的代码组织在一起，并通过名称进行调用的结构。

Python 使用 `def` 关键字定义函数。

基本语法：

```python
def function_name():
    # 函数体
    print("执行函数")
```

例如：

```python
def say_hello():
    print("欢迎使用 AI Agent 学习系统")

say_hello()
```

运行结果：

```text
欢迎使用 AI Agent 学习系统
```

**知识要点：**

1. `def` 用于定义函数。
2. 函数名通常采用小写字母与下划线组合的命名方式。
3. 函数定义后不会立即执行函数体。
4. 调用函数时，需要在函数名后添加括号 `()`。
5. 函数体使用缩进表示，通常为四个空格。
6. 同一个函数可以被多次调用。

例如：

```python
def show_message():
    print("正在学习 Python 函数")

show_message()
show_message()
```

运行结果：

```text
正在学习 Python 函数
正在学习 Python 函数
```

### 2.2 函数的执行顺序

Python 执行到函数定义语句时，会创建函数对象，但不会立即执行函数内部的代码。

例如：

```python
print("程序开始")

def show_message():
    print("正在执行函数")

print("函数定义完成")

show_message()

print("程序结束")
```

运行结果：

```text
程序开始
函数定义完成
正在执行函数
程序结束
```

**执行过程：**

1. 输出“程序开始”。
2. 执行 `def`，完成函数定义。
3. 输出“函数定义完成”。
4. 调用 `show_message()`。
5. 执行函数内部代码。
6. 函数执行结束，返回调用位置。
7. 输出“程序结束”。

**重要结论：函数定义和函数调用是两个不同的操作。**

### 2.3 函数参数：形参与实参

参数用于向函数传递数据。

例如：

```python
def greet(name):
    print(f"你好，{name}")

greet("小明")
greet("小红")
```

运行结果：

```text
你好，小明
你好，小红
```

**形参与实参：**

| 概念 | 含义 | 示例 |
|---|---|---|
| 形参 Parameter | 定义函数时声明的参数 | `name` |
| 实参 Argument | 调用函数时传入的实际数据 | `"小明"` |

**多个参数：**

```python
def introduce(name, age):
    print(f"我叫{name}，今年{age}岁")

introduce("小明", 24)
```

运行结果：

```text
我叫小明，今年24岁
```

**知识要点：**

- 函数可以没有参数。
- 函数可以有一个或多个参数。
- 位置实参按照顺序与形参对应。
- 参数能够提高函数的通用性，避免为不同数据重复编写函数。

### 2.4 return 返回值与 print() 的区别

`return` 用于将函数执行结果返回给调用者。

例如：

```python
def calculate_sum(a, b):
    total = a + b
    return total

result = calculate_sum(10, 20)

print(result)
```

运行结果：

```text
30
```

**return 与 print() 的区别：**

| 对比 | print() | return |
|---|---|---|
| 主要作用 | 输出内容 | 返回结果 |
| 是否直接显示到终端 | 是 | 否 |
| 能否由调用者保存结果 | 不自动提供结果 | 可以 |
| 是否结束当前函数 | 否 | 是 |
| 典型用途 | 信息展示 | 计算与数据传递 |

例如：

```python
def calculate_square(number):
    return number ** 2

result = calculate_square(5)

print(result)
print(result + 10)
```

运行结果：

```text
25
35
```

**重要规则：**

1. 执行 `return` 后，当前函数立即结束。
2. `return` 后面未执行的函数体语句不会继续执行。
3. 没有显式返回值的函数，默认返回 `None`。
4. 计算函数通常优先使用 `return`，由调用者决定是否打印结果。

### 2.5 局部变量与全局变量

变量作用域决定变量能够在哪些位置被访问。

**局部变量：**

在函数内部定义的变量通常属于该函数的局部作用域。

```python
def show_student():
    name = "小明"
    print(name)

show_student()
```

函数内部的 `name` 不能直接通过函数外部的同名变量访问。

**全局变量：**

在模块顶层定义的变量称为全局变量。

```python
school = "AI Agent 学习系统"

def show_school():
    print(school)

show_school()
```

运行结果：

```text
AI Agent 学习系统
```

**同名变量：**

```python
name = "全局小明"

def show_name():
    name = "局部小红"
    print(f"函数内部：{name}")

show_name()
print(f"函数外部：{name}")
```

运行结果：

```text
函数内部：局部小红
函数外部：全局小明
```

**重要结论：**

函数内部创建的同名局部变量不会自动修改函数外部的全局变量。

可以通过 `return` 将函数内部计算结果传递给调用者。

### 2.6 默认参数与关键字参数

#### 默认参数

默认参数是在定义函数时为某些参数提供默认值。

例如：

```python
def greet(name="同学"):
    print(f"你好，{name}")

greet()
greet("小明")
```

运行结果：

```text
你好，同学
你好，小明
```

当调用者没有传入参数时，使用默认值；传入参数时，使用新的值。

多个参数示例：

```python
def introduce(name, major="计算机科学与技术"):
    print(f"姓名：{name}")
    print(f"专业：{major}")

introduce("小明")
introduce("小红", "人工智能")
```

**重要规则：**

普通位置参数中，没有默认值的参数应放在具有默认值的参数之前。

#### 关键字参数

关键字参数允许调用者明确指定参数名称。

```python
def student_info(name, age, score):
    print(f"{name}，{age}岁，成绩{score}")

student_info(name="小明", score=95, age=24)
```

运行结果：

```text
小明，24岁，成绩95
```

**知识要点：**

- 位置参数主要依据参数顺序传递。
- 关键字参数通过参数名称传递。
- 关键字参数可以提高调用代码的可读性。
- 在一般函数调用中，位置实参需要放在关键字实参之前。

### 2.7 函数之间的调用与代码复用

一个函数可以调用其他函数。

例如：

```python
def get_grade(score):
    if score >= 90:
        return "优秀"
    else:
        return "其他等级"

def show_report(name, score):
    grade = get_grade(score)
    print(f"{name}：{score}，等级：{grade}")

show_report("小明", 95)
```

运行结果：

```text
小明：95，等级：优秀
```

**知识要点：**

1. 不同函数可以承担不同职责。
2. 公共逻辑可以提取为独立函数。
3. 其他函数可以调用这些公共函数。
4. 修改公共逻辑时，不需要重复修改多个位置。

在学生成绩管理系统 V2 中，`add_student()` 和 `update_student()` 都调用 `is_valid_score()`，就是一次实际的函数复用。

### 2.8 可变对象参数与主程序入口

#### 字典作为函数参数

字典属于可变对象。

```python
def add_example(students):
    students["小明"] = 95

student_data = {}
add_example(student_data)

print(student_data)
```

运行结果：

```text
{'小明': 95}
```

函数通过参数接收字典，并直接修改字典内容。

因此，学生成绩管理系统不需要依赖 `global` 就可以在不同函数中管理同一份学生数据。

需要注意，修改字典的内容与在函数内部把参数名称重新绑定到新字典，是不同的操作。

#### 主程序入口

```python
if __name__ == "__main__":
    print("程序启动")
```

当当前文件被直接运行时，条件成立。

当文件被其他模块导入时，这部分代码通常不会自动执行。

**使用原则：**

- 函数定义可以放在文件前面。
- 主程序入口放在后面。
- 主程序主要负责组织函数调用。
- 独立功能优先写成函数，提高代码复用性。

```python
# 定义全局变量
school = "AI Agent 学习系统"
name = "全局小明"

def show_info():
```

- 模块顶层定义的变量属于全局变量。

- 局部变量可以与全局变量同名。
- 同名局部变量不会自动修改全局变量。
- `return` 可以将计算结果交给函数外部。
- 不同作用域中可以使用相同变量名。

#### ⑥ 改进方向

- 避免过度依赖全局变量。
- 优先通过参数传递数据。
- 优先通过 `return` 返回结果。

### 3.4 练习四：函数综合练习

**文件路径：** `code/function_practice.py`

#### ① 练习目标

综合掌握列表参数、循环累加、返回值、多分支判断、默认参数、关键字参数以及函数之间的调用。

#### ② 题目要求

- 定义 `calculate_average(scores)`。
- 使用 `for` 循环计算平均分并返回。
- 定义 `get_grade(score)`。
- 按成绩范围返回不同等级。
- 定义 `print_student_report(name, score, subject="Python")`。
- 在报告函数中调用 `get_grade()`。
- 使用默认参数输出 Python 课程报告。
- 使用关键字参数输出 AI Agent 课程报告。
- 验证非法成绩 105 的等级。

成绩等级规则：

| 分数 | 等级 |
|---|---|
| 90–100 | 优秀 |
| 80–89 | 良好 |
| 60–79 | 及格 |
| 0–59 | 不及格 |
| 小于 0 或大于 100 | 无效 |

#### ③ 完整代码

```python
# 计算平均分
def calculate_average(scores):
    # 初始化总成绩
    total = 0

    # 循环计算总成绩
    for score in scores:
        total += score

    # 返回平均分
    return total / len(scores)

# 获取成绩等级
def get_grade(score):
    if score < 0 or score > 100:
        grade = "无效"
    elif score >= 90:
        grade = "优秀"
    elif score >= 80:
        grade = "良好"
    elif score >= 60:
        grade = "及格"
    else:
        grade = "不及格"

    # 返回成绩等级
    return grade

# 输出学生成绩报告
def print_student_report(name, score, subject="Python"):
    # 获取成绩等级
    grade = get_grade(score)

    # 输出学生成绩报告
    print(f"姓名：{name}\n课程：{subject}\n成绩：{score}，等级：{grade}")

if __name__ == '__main__':
    # 成绩列表
    scores = [85, 92, 76, 88, 95]

    # 班级成绩统计
    average = calculate_average(scores)
    print("==== 班级成绩统计 ====")
    print(f"班级平均分：{average:.2f}")
    print()
```

## 四、今日编程规范总结

### 4.1 函数命名要准确清晰

函数名称应能够表达其作用。

例如：

```python
def calculate_average(scores):
    pass
```

避免使用意义不明确的函数名，也要注意拼写一致。

### 4.2 一个函数尽量负责一项功能

例如：

- `show_menu()` 只负责显示菜单。
- `is_valid_score()` 只负责校验成绩。
- `add_student()` 负责添加学生。
- `query_student()` 负责查询学生。

将不同职责拆分，可以提高代码的可读性和可维护性。

### 4.3 正确区分 print() 和 return

需要显示信息时使用 `print()`。

需要向调用者提供结果时使用 `return`。

计算函数应优先返回结果，避免只能通过终端查看计算值。

### 4.4 优先通过参数传递数据

尽量避免所有函数直接依赖全局变量。

例如：

```python
def show_count(students):
    return len(students)
```

这样可以明确函数需要哪些数据。

### 4.5 合理复用公共逻辑

当多个函数执行相同判断时，可以提取公共函数。

例如：

```python
if is_valid_score(score):
    print("成绩有效")
```

本次项目中的添加和修改功能都复用了成绩校验逻辑。

### 4.6 注意函数内部的缩进

`if`、`for`、`while` 嵌套时，不同缩进会影响代码执行次数和执行条件。

尤其需要明确某条语句是否应该在循环内部重复执行。

### 4.7 主程序入口与功能函数分离

可以使用：

```python
if __name__ == '__main__':
    # 主程序逻辑
    pass
```

让函数定义与程序启动逻辑分开。

这有助于以后导入模块、编写测试及复用代码。

## 五、今日问题与反思

### 5.1 函数名称拼写错误

**问题：** 第 1 课将 `show_welcome()` 写成了 `show_welcom()`。

**原因：** 函数定义和调用虽然一致，但与题目规定的接口名称不一致。

**解决方法：** 同时检查定义位置和调用位置，确保函数名称准确。

**学习收获：** 函数命名需要符合约定，而不仅仅是保证当前程序能运行。

### 5.2 return 与 print() 的区别

**问题：** 函数计算结果应该直接输出，还是返回给调用者？

**分析：** 如果希望调用者保存结果并参与后续计算，应使用 `return`。

**学习收获：** `return` 能够使函数更加通用，计算逻辑不必与输出逻辑绑定。

### 5.3 局部变量与全局变量同名

**问题：** 函数内部创建同名变量是否会修改外部变量？

**分析：** 函数内部创建的局部变量与模块级同名变量属于不同的作用域。

**学习收获：** 应通过参数和返回值明确传递数据，减少变量作用域造成的理解困难。

### 5.4 默认参数与关键字参数

**问题：** 如何让函数既支持默认配置，又支持调用时指定不同配置？

**解决方法：** 使用默认参数与关键字参数。

**学习收获：** 函数参数设计能够提高代码复用性和可读性。

### 5.5 显示学生信息时成功提示重复

**问题：** `show_all_students()` 每显示一名学生就输出一次成功提示。

**原因：** 成功提示位于 `for` 循环内部。

**解决方法：** 将成功提示移动到 `for` 循环外部，并保留在非空字典分支内部。

**学习收获：** 缩进不仅影响代码结构，还会直接影响语句执行的次数。

### 5.6 函数化重构的意义

**问题：** 如何避免一个程序的所有功能都写在同一个 `while` 循环中？

**解决方法：** 将不同功能拆分为独立函数，并由主循环按菜单选项调用。

**学习收获：** 函数化重构能够减少代码重复，提高程序的清晰度、可扩展性和可维护性。
