## 二、核心知识点

### 2.1 Python 程序的基本执行方式

Python 是一种高级编程语言，可以使用 Python 解释器执行 `.py` 源代码文件。

例如，创建 `hello.py`：

```python
print("Hello, Python!")
```

在终端执行：

```powershell
python hello.py
```

输出：

```text
Hello, Python!
```

**知识要点：**

- `.py` 是 Python 源代码文件的常见扩展名。
- `print()` 是 Python 的内置输出函数。
- Python 程序通常按照代码的执行顺序运行。
- 字符串可以使用单引号或双引号表示。
- `#` 用于编写单行注释。

### 2.2 变量与数据类型

变量可以理解为指向某个数据对象的名称。

基本赋值语法：

```python
变量名 = 值
```

例如：

```python
name = "唐天成"
age = 24
height = 185.5
is_student = True
```

Python 中常见的四种基本数据类型：

| 数据类型 | 含义 | 示例 |
|---|---|---|
| `str` | 字符串 | `"Python"` |
| `int` | 整数 | `24` |
| `float` | 浮点数 | `185.5` |
| `bool` | 布尔值 | `True`、`False` |

可以使用 `type()` 查看数据类型：

```python
print(type(name))
print(type(age))
print(type(height))
print(type(is_student))
```

输出：

```text
<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>
```

**注意事项：**

1. `=` 表示赋值，`==` 表示比较是否相等。
2. 变量名推荐使用下划线命名法（snake_case）。
3. `True` 和 `False` 首字母必须大写。
4. `24` 是整数，`"24"` 是字符串。
5. Python 是动态类型语言，变量名不需要预先声明固定的数据类型。

### 2.3 print() 与 input()

#### print()：输出信息

```python
name = "小明"
print(name)
```

输出：

```text
小明
```

#### input()：接收用户输入

```python
name = input("请输入姓名：")
print(name)
```

程序会等待用户输入，用户按下回车后继续执行。

**重要结论：`input()` 返回的数据类型始终是字符串 `str`。**

例如：

```python
age = input("请输入年龄：")
print(type(age))
```

即使用户输入 `24`，输出仍然是：

```text
<class 'str'>
```

### 2.4 数据类型转换

为了进行数值计算，可以使用类型转换函数。

| 函数 | 作用 | 示例 |
|---|---|---|
| `int()` | 转换为整数 | `int("24")` |
| `float()` | 转换为浮点数 | `float("185.5")` |
| `str()` | 转换为字符串 | `str(24)` |

例如：

```python
age = int(input("请输入年龄："))
height = float(input("请输入身高（cm）："))
```

执行过程：

1. `input()` 接收用户输入。
2. `int()` 或 `float()` 进行类型转换。
3. 将转换后的数据赋值给变量。

如果输入内容无法转换，则可能出现异常。

例如：

```python
age = int("hello")
```

会触发 `ValueError`。

后续学习异常处理时再解决此类问题。

### 2.5 f-string 格式化输出

f-string 是 Python 中常用的字符串格式化方式。

基本语法：

```python
name = "小明"
age = 24

print(f"姓名：{name}")
print(f"年龄：{age} 岁")
```

输出：

```text
姓名：小明
年龄：24 岁
```

特点：

- 在字符串前添加 `f`。
- 使用 `{}` 插入变量或表达式。
- 可以直接在 `{}` 中进行计算。
- 可以控制数值的输出格式。

例如：

```python
a = 10
b = 3

print(f"加法：{a + b}")
print(f"除法：{a / b:.2f}")
```

输出：

```text
加法：13
除法：3.33
```

其中 `:.2f` 表示以定点小数形式显示两位小数。

### 2.6 Python 算术运算符

| 运算符 | 作用 | 示例 | 结果 |
|---|---|---|---|
| `+` | 加法 | `10 + 3` | `13` |
| `-` | 减法 | `10 - 3` | `7` |
| `*` | 乘法 | `10 * 3` | `30` |
| `/` | 普通除法 | `10 / 3` | `3.333...` |
| `//` | 向下取整除法 | `10 // 3` | `3` |
| `%` | 取余 | `10 % 3` | `1` |
| `**` | 幂运算 | `10 ** 3` | `1000` |

#### 重点区别

**普通除法 `/`**

```python
print(10 / 3)
```

结果约为 `3.3333333333333335`。

**整除 `//`**

```python
print(10 // 3)
```

输出为 `3`。

需要注意，Python 的整除是向负无穷方向取整。

```python
print(-10 // 3)
```

输出为 `-4`。

**取余 `%`**

```python
print(10 % 3)
```

输出为 `1`。

**幂运算 `**`**

```python
print(2 ** 3)
```

输出为 `8`。

### 2.7 运算符优先级

基本运算优先级：

1. 括号 `()`
2. 幂运算 `**`
3. 乘除相关运算 `*`、`/`、`//`、`%`
4. 加减运算 `+`、`-`

例如：

```python
result = 2 + 3 * 4
print(result)
```

结果为 `14`。

如果希望先计算加法：

```python
result = (2 + 3) * 4
print(result)
```

结果为 `20`。

复杂表达式建议使用括号明确计算顺序。

### 3.6 练习六：BMI 计算器综合实战

**文件路径：** `code/bmi_calculator.py`

#### ① 练习目标

综合运用变量、用户输入、数据类型转换、算术运算和 f-string，完成一个完整的小型 Python 程序。

#### ② 题目要求

- 接收用户姓名。
- 接收身高，单位为厘米。
- 接收体重，单位为千克。
- 将身高从厘米转换为米。
- 使用 BMI 公式完成计算。
- 将 BMI 结果保留两位小数。
- 输出用户信息和计算结果。

**BMI 数学公式：**

$$
\mathrm{BMI} = \frac{m}{h^2}
$$

其中：

- `m` 表示体重，单位 kg。
- `h` 表示身高，单位 m。

身高单位转换公式：

$$
h = \frac{h_{cm}}{100}
$$

例如，体重为 70 kg，身高为 175 cm：

$$
\mathrm{BMI} = \frac{70}{1.75^2} \approx 22.86
$$

#### ③ 完整代码

```python
# BMI 计算器

# 获取用户输入
name = input("请输入姓名：")
height_cm = float(input("请输入身高（cm）："))
weight_kg = float(input("请输入体重（kg）："))

# 单位转换
height_m = height_cm / 100

# 计算 BMI
bmi = weight_kg / height_m ** 2

# 输出结果
print("==== BMI 计算结果 ====")
print(f"姓名：{name}")
print(f"身高：{height_cm} cm")
print(f"体重：{weight_kg} kg")
print(f"BMI: {bmi:.2f}")
```

#### ④ 运行结果

输入姓名为小明、身高为 175 cm、体重为 70 kg 时：

```text
请输入姓名：小明
请输入身高（cm）：175
请输入体重（kg）：70
==== BMI 计算结果 ====
姓名：小明
身高：175.0 cm
体重：70.0 kg
BMI: 22.86
```

#### ⑤ 知识总结

**1. 理解完整程序的执行流程**

用户输入 → 类型转换 → 单位转换 → 数学计算 → 格式化输出。

**2. 理解中间变量的作用**

```python
height_m = height_cm / 100
bmi = weight_kg / height_m ** 2
```

通过中间变量将复杂计算分解为多个步骤，可以提高代码的可读性。

**3. 掌握数学公式到代码的转换**

公式中的平方运算对应 Python 中的 `** 2`。

**4. 理解运算符优先级**

`**` 的优先级高于 `/`，因此程序会先计算身高的平方，再计算 BMI。

#### ⑥ 改进方向

- 使用 `if / else` 检查身高和体重是否为正数。
- 对非数字输入增加异常处理。
- 统一输出标点与格式。
- 后续可以增加 BMI 分类功能。
- 学习函数后，将 BMI 计算逻辑封装成独立函数。

## 五、今日问题与反思

### 5.1 input() 返回字符串

**问题：** 用户输入数字之后，为什么还需要调用 `int()` 或 `float()`？

**原因：** `input()` 返回的数据类型是字符串。

**解决方法：** 在需要进行数值计算时，先进行类型转换。

### 5.2 算术运算符的区别

需要重点区分：

- `/`：普通除法。
- `//`：向下取整除法。
- `%`：取余。
- `**`：幂运算。

### 5.3 运算符优先级

复杂表达式需要注意运算符优先级。

建议通过括号明确数学计算顺序。

### 5.4 BMI 计算器缺少输入校验

**问题：** 当用户输入身高为 0 时，程序会报错。

**原因：** BMI 公式需要使用身高的平方作为分母，分母不能为 0。

**改进方向：** 后续使用条件判断检查输入数据，并使用异常处理机制处理错误情况。

### 5.5 代码可读性

在编程过程中，应优先使用有意义的变量名，并适当使用注释和中间变量。
